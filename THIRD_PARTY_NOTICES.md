## PresentMon (Intel Corporation)

Frametrace runs the PresentMon console application to capture frame data. Release builds of
Frametrace bundle `PresentMon-2.6.0-x64.exe` from
https://github.com/GameTechDev/PresentMon/releases/tag/v2.6.0. They ship it unmodified, next to
PresentMon's own `LICENSE.txt` and `THIRD_PARTY.txt` (as `PresentMon-LICENSE.txt` and
`PresentMon-THIRD_PARTY.txt`). The git repository doesn't contain PresentMon.
`tools/get_presentmon.py` downloads it together with both notice files.
