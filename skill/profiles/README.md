# Game profiles

Optional, community-written knowledge about individual games. The skill loads a profile when the
report's process name matches one listed in the profile's `process_names`.

Rules:
- One file per game: `<game-slug>.md`, based on `_template.md`.
- Profiles add knowledge. Frametrace and the skill must still work without them.
- State facts you've checked, preferably with a Frametrace before/after. Mark anything unverified.
- No affiliate links or promotions.
